# Playbooks

`social-media-skills/` holds selected guides from the **Social Media Skills** plugin by Frank Heijdenrijk
(MIT licence, see `social-media-skills/LICENSE`), copied here so the weekly MyGroom content runs can read
them even when the plugin isn't loaded. Each folder has a `SKILL.md` plus `references/`.

Used by the weekly run:
- `viral-reverse-engineering` - why a standout video worked (used with vidIQ outlier results)
- `hook-writer` - opening lines and slide-1 covers
- `tiktok-script`, `reels-script` - structure and timing for reels
- `carousel-writer`, `tiktok-photo-mode` - the weekly swipeable post
- `caption-writer` - captions
- `reply-and-comment-writer` - drafting comment replies

The guides mention a publishing tool called WoopSocial; MyGroom publishes through Metricool instead.
